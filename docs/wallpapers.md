# Обои

- `bg.webp`, `bg_m.webp` — обои прежней алой темы по умолчанию (с v1.7.21 тема «алая», копия в `themes/crimson/`).
- `bg_blue.webp`, `bg_blue_m.webp` — обои бывшего примера «Синяя ночь» (из README убран в v1.7.21; файлы оставлены для стилей со старой ссылкой).
- `bg_purple_sky*.webp`, `banner_purple.webp` — с v1.7.21 копии в `themes/purple/` (тема «фиолетовое небо»); в корне оставлены для старой ссылки `…/main/…`.
- Обои готовых тем и их источники — в README, раздел «Готовые темы».

Синие обои сделаны из фотографии [Kanchenjunga South Peak](https://commons.wikimedia.org/wiki/File:Kanchenjunga_South_Peak_%28Unsplash%29.jpg) (Mukesh Jain, Unsplash, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)): обрезаны под 2560×1440 (ПК) и 900×1440 (телефон) и сохранены в WebP.
